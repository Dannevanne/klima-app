# PLEASE READ BEFORE COMMITING

**Do** prefix all commit messages with their respective type, followed by a colon. Examples:
- `feat: <something something>`
- `fix: <something something>`
- `add: <new file>`
- `refactor: <what was refactored?>`


**Do** prefix all branches with their respective type, followed by a slash Examples:
- `feat/<a-new-branch>`
- `fix/<a-new-fix-branch>`
- `refactor/<something-something>`
- `test/<new-tests>`

**Do not** squash commits in the PR unless totally necessary

**Do** comment thoroughtly, *and only in English*

**Do** commit incrementally -- we favor small commits over big ones.

**Do** use trunk-based development: short-lived feature branches off `main`, merged fast.

**Do** keep PRs focused: one logical change per PR.
